Geo Collector — инструмент для полевого сбора географических точек. Работает офлайн, без регистрации; все данные хранятся на устройстве.

Частые вопросы

Приложение просит доступ к геолокации. Обязательно разрешать?

Нет. Без доступа останется ручной ввод координат, карта, список, поиск, фильтры, импорт и экспорт — то есть всё, кроме автоматического определения координат. Разрешение можно выдать позже в «Настройки → Geo Collector → Геопозиция».

Координаты определяются неточно

Точность показана рядом с координатами при создании точки. Нажмите «Обновить координаты», когда значение станет меньше: на открытом месте приёмник уточняет позицию в течение нескольких секунд. Внутри помещений точность обычно хуже.

Куда делся экспортированный файл?

Приложение не хранит экспортированные файлы — оно передаёт их системному меню «Поделиться», а вы выбираете, куда их отправить: «Файлы», iCloud Drive, почта, AirDrop. Если меню закрылось случайно, просто выполните экспорт ещё раз.

Какие файлы можно импортировать?

Файлы .geojson и .json со структурой FeatureCollection. В текущей версии импортируется только геометрия Point; линии и полигоны пропускаются.

Почему часть объектов пропущена при импорте?

Перед записью приложение показывает предпросмотр с причинами: неподдерживаемая геометрия, отсутствующая геометрия, координаты вне допустимого диапазона. Один некорректный объект не прерывает импорт остальных.

Почему точки не добавились при повторном импорте?

Это защита от дублей. Точка считается дубликатом, если в этом же проекте уже есть объект с теми же координатами, названием, описанием, высотой, точностью и набором тегов. Количество таких точек показано в предпросмотре и в итоговом сообщении.

Карта серая или пустая

Картографические изображения загружаются из сети. Офлайн отображаются только ранее загруженные фрагменты; маркеры, координаты, список и экспорт при этом работают.

В CSV вместо русских букв непонятные символы

Файл в UTF-8 с BOM, и Excel открывает его корректно. Если редактор всё же показывает иное, выберите при открытии кодировку UTF-8.

Как перенести данные на другое устройство?

Экспортируйте проект в GeoJSON, передайте файл на второе устройство и импортируйте его там. Сохранятся координаты, названия, описания, теги, высота, точность и даты создания.

Можно ли восстановить удалённый проект?

Нет. Данные хранятся только на устройстве, резервных копий у разработчика не существует. Перед удалением имеет смысл выполнить экспорт.

Frequently asked questions

The app asks for location access. Is it required?

No. Without it you keep manual coordinate entry, the map, the list, search, filters, import and export — everything except automatic positioning. You can grant access later in Settings → Geo Collector → Location.

Coordinates are not accurate

The accuracy figure is shown next to the coordinates while creating a point. Tap "Обновить координаты" (Refresh coordinates) once the value drops: in the open the receiver refines its position over a few seconds. Indoors accuracy is usually worse.

Where did the exported file go?

The app does not keep exported files — it hands them to the system share sheet and you choose the destination: Files, iCloud Drive, email, AirDrop. If the sheet was dismissed by accident, simply export again.

Which files can be imported?

Files with the .geojson or .json extension containing a FeatureCollection. This version imports Point geometry only; lines and polygons are skipped.

Why were some objects skipped during import?

Before writing anything, the app shows a preview with the reasons: unsupported geometry, missing geometry, or coordinates out of range. One malformed object never aborts the rest of the import.

Why were no points added when I imported the same file again?

That is duplicate protection. A point counts as a duplicate when the same project already holds an object with identical coordinates, name, description, altitude, accuracy and tag set. The number of such points is shown in the preview and in the final message.

The map is grey or empty

Map imagery is loaded from the network. Offline, only previously loaded tiles appear; markers, coordinates, the list and export keep working.

CSV shows garbled characters instead of Cyrillic

The file is UTF-8 with a BOM and opens correctly in Excel. If your editor still shows otherwise, choose UTF-8 encoding when opening it.

How do I move data to another device?

Export the project to GeoJSON, transfer the file to the second device and import it there. Coordinates, names, descriptions, tags, altitude, accuracy and creation dates are preserved.

Can a deleted project be restored?

No. Data lives only on the device and the developer keeps no backups. It is worth exporting before deleting.
