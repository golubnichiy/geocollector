# Geo Collector — публичные страницы

Этот репозиторий содержит только публичную справку приложения Geo Collector для iOS:

- `privacy/` — политика конфиденциальности
- `support/` — страница поддержки
- `index.html` — короткая страница со ссылками на обе

Исходный код приложения здесь **не публикуется** и находится в отдельном закрытом репозитории.

## Публикация

Страницы отдаются GitHub Pages из корня ветки `main`. Файл `.nojekyll` отключает обработку Jekyll: это обычные HTML-страницы, которые отдаются как есть.

Адреса:

- https://golubnichiy.github.io/geocollector/privacy/
- https://golubnichiy.github.io/geocollector/support/

Первый из них указан в App Store Connect как Privacy Policy URL и внутри приложения на экране «О приложении». Второй — как Support URL.

**Важно:** эти адреса публичны и указаны в карточке приложения в App Store, поэтому их нельзя менять без одновременного обновления `app.json` (`expo.extra.privacyPolicyUrl`, `expo.extra.supportUrl`) и полей в App Store Connect. Переименование репозитория сломает обе ссылки.

## Правки

Страницы двуязычные: русская часть для пользователей, английская — для проверки в App Review. При изменении политики по существу нужно обновить дату вступления в силу в обеих частях.
